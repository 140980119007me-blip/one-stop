# ONE STOP Android Studio Project (V3)

This is an Android WebView wrapper of the ONE STOP V3 web interface, with bundled UI assets and optional location permissions.

## Build APK
1. Install Android Studio (current stable) and Android SDK Platform 35.
2. Open this folder in Android Studio.
3. Allow Gradle sync to finish.
4. Select **Build > Build APK(s)**.
5. APK output will be under `app/build/outputs/apk/debug/app-debug.apk`.

This environment did not have Android SDK/Gradle installed, so an APK could not be compiled here. This project is source-ready for Android Studio, but the marketplace backend must be hosted and configured before real account, booking, payment or technician data work across devices. The interface may be opened offline; API features need a backend.
